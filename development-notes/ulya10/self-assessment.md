## Описание моей работы

### Что я сделала в рамках проекта

Занималась разработкой frontend-части приложения Tandem — интерактивного тренажёра для подготовки к техническим интервью. Моя работа включала:

1. **Landing Page** — главная страница приложения с описанием функционала, карточками виджетов, списком тем и кнопкой с CTA.
2. **Header** — компонент шапки с адаптивной навигацией, кнопками входа/выхода, переключением темы и языка.
3. **True/False Widget** — виджет для проверки знаний, где пользователь должен определить, истинно или ложно утверждение.
4. **Code Completion Widget** — интерактивный виджет для тренировки навыков написания кода с заполнением пропусков.
5. **Адаптивная вёрстка** — корректное отображение Header и Landing Page на всех устройствах (от 320px).
6. **Unit-тесты** — написание тестов для проверки логики Landing Page.

### Технологии и инструменты

- **TypeScript** — типизация кода
- **CSS Flexbox** — для создания адаптивных сеток
- **Vitest + Happy DOM** — для unit-тестирования

## 2+ личных Feature Component

### 1. True/False Widget

Интерактивный виджет, где пользователь видит утверждение и должен выбрать True (правда) или False (ложь).

**Функциональность:**

- Пользователь видит утверждение (например: "Promise.all возвращает результаты в порядке завершения")
- Нажимает кнопку "True" или "False"
- Выбранный ответ подсвечивается
- После нажатия "Submit" ответ отправляется на проверку
- Кнопки блокируются, чтобы нельзя было изменить ответ

**Реализовано:**

- Управление состоянием выбранного ответа
- Визуальная обратная связь (подсветка активной кнопки)
- Блокировка интерфейса после отправки

### 2. Code Completion Widget — 0-25 баллов

Интерактивный виджет, где пользователь видит фрагмент кода с пропуском и должен ввести правильное слово/метод.

**Функциональность:**

- Отображение кода с выделенным местом для ввода
- Поле ввода для каждого пропуска
- Отправка ответа на проверку

**Реализовано:**

- Парсинг строки кода для вставки input в нужное место
- Работа с несколькими пропусками в одной строке

### 3. Landing Page — 0-20 баллов

Главная страница приложения, которая приветствует пользователя и показывает доступные возможности.

**Функциональность:**

- Cекция с заголовком и кнопкой CTA "Begin training!"
- Секция с карточками виджетов (6 карточек, создаются динамически из массива)
- Секция с доступными темами (Core-JS, Algorithms, Typescript)

**Сложная логика и состояние:**

- Адаптивная сетка карточек (4 → 1 колонка в зависимости от экрана)
- Динамическое создание элементов через циклы
- CSS Flexbox для расположения карточек
