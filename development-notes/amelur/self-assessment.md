## 2. Описание работы

В рамках проекта была реализована клиентская часть приложения с авторизацией, интерактивными компонентами и базовой архитектурой фронтенда.  
Основной упор сделан на работу с пользовательскими сценариями (регистрация, вход, восстановление пароля), а также на интерактивность интерфейса.

Использовались современные инструменты фронтенда:
- JavaScript / TypeScript
- модульная структура приложения
- работа с DOM
- интеграция с BaaS (Firebase) для аутентификации пользователей


### Реализованные фичи

#### Register Page
Реализована форма регистрации с валидацией пользовательских данных и интеграцией с Firebase для создания аккаунта.

#### Login Page
Добавлена страница входа с обработкой ошибок и авторизацией через Firebase.

#### Forgot Password Page
Реализован механизм восстановления пароля через отправку email.

#### CodeOrderingWidget
Создан интерактивный компонент, позволяющий пользователю упорядочивать элементы (например, код) в правильной последовательности.

#### Drag & Drop
Добавлена возможность перетаскивания элементов для улучшения пользовательского опыта (используется в виджете).

#### Responsive Design
Интерфейс адаптирован под разные размеры экранов с использованием flexbox и grid.

#### Unit Tests (Basic)
Написаны базовые тесты для ключевых компонентов и бизнес-логики.

#### Firebase Auth
Настроена аутентификация пользователей (регистрация, вход, восстановление пароля).

## 2 личных Feature Component

## 1. Login Page (Authentication)

Я самостоятельно реализовал страницу входа пользователя.

Создана форма с обработкой пользовательского ввода:
- валидация данных (пустые поля, корректность email)
- отображение ошибок пользователю
- отправка данных на сервер

Реализована логика авторизации:
- подключение к Supabase
- выполнение запроса на вход
- обработка успешного и неуспешного ответа

Особое внимание уделено:
- UX (понятные сообщения об ошибках)
- разделению логики и UI
- обработке edge-кейсов


## 2. Supabase Authentication Integration

Я самостоятельно реализовал интеграцию аутентификации с использованием Supabase.

Настроено:
- подключение Supabase клиента
- регистрация и авторизация пользователей
- работа с сессией пользователя

Реализована логика:
- отправка запросов к Supabase Auth API
- обработка ответов и ошибок
- хранение состояния авторизации

Основные сложности:
- понимание работы auth flow
- обработка асинхронных операций
- синхронизация данных между UI и сервером
